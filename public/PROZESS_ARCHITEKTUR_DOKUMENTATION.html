Das Gesamtsystem: Zusammenspiel aller Dienste

Flow der Stille läuft als moderne Web- und native Android-App. Um maximale Geschwindigkeit, Offline-Fähigkeit und geschütztes Audio-Streaming zu garantieren, sind 5 spezialisierte Dienste nahtlos miteinander verzahnt:

Hostinger

Web & Mail

Liefert die HTML/JS/CSS Web-App via LiteSpeed aus und verwaltet die Domain flow-der-stille.de inkl. E-Mail Postfächer.

Supabase

DB & Auth

PostgreSQL-Datenbank für Produkte, Käufe, Google SSO Login und Benutzerprofile (Admin/User Rollen).

Cloudflare

Audio Streaming

Cloudflare R2 / CDN speichert die großen MP3-Dateien und liefert sie blitzschnell mit HTTP-Range Streaming aus.

Google Play

Android App

Google Play Console verwaltet die App-Releases und In-App-Produkte (In-App-Kauf IDs für Android-Nutzer).

Antigravity / Git

Entwicklung

Source Code Verwaltung, Kapitel-Konfiguration, Offline-Cache-Logik und Build-Prozess (npm run build).

Ablauf: Neues Hörbuch / Produkt anlegen & freischalten

Folge exakt diesen 6 Schritten, um ein neues Hörbuch fehlerfrei im System zu hinterlegen, sodass es sowohl auf der Webseite als auch in der Android-App kaufbar und abspielbar ist:

1
Audio-Datei (MP3) in Cloudflare hochladen Cloudflare R2

• Logge dich bei Cloudflare ein und öffne den R2-Bucket für Flow der Stille.
• Lade die fertige MP3-Datei hoch (z. B. Mut zum echtsein.....mp3).
• Kopiere die öffentliche Streaming-URL der Datei (diese wird in Schritt 3 benötigt).

2
Produktbild / Cover erstellen & hinterlegen Antigravity / Assets

• Quadratisches Cover-Bild im Verhältnis 1:1 anlegen (z. B. 1000 × 1000 Pixel JPG).
• Datei im Projektordner unter src/assets/images/products/ und dist/images/products/ speichern (z. B. cover_mensch_sein.jpg).

3
Datensatz in Supabase Tabelle „produkte“ anlegen Supabase Database

Öffne in Supabase den Table Editor und wähle die Tabelle produkte. Klicke auf Insert Row und fülle folgende Felder aus:

idEindeutiger System-Schlüssel (z. B. mensch_sein oder fds_mensch_sein)
titelExakter Buchtitel (z. B. Mut zum Echtsein - Was steckt hinter einem echten Menschen)
beschreibungKlappentext / Inhaltsbeschreibung für die Detail- und Shopansicht
preis / dauerVerkaufspreis in Euro (z. B. 4.99) und Gesamtdauer in Sekunden (z. B. 3519)
audio_pathDie in Schritt 1 kopierte Cloudflare-Streaming-URL der MP3-Datei
cover_pathRelativer Bildpfad (z. B. /images/products/cover_mensch_sein.jpg)
play_store_idGoogle In-App Produkt-ID (z. B. fds_mensch_sein) – Wichtig für Android!
kategorieWert auf hoerbuch setzen (weitere: meditation, self_hypnosis)
4
In-App-Produkt in der Google Play Console anlegen Google Play Console

• Gehe zu Google Play Console > App auswählen > Monetarisieren > In-App-Produkte.
• Klicke auf Produkt erstellen und trage dieselbe ID wie in Supabase ein: fds_mensch_sein.
• Titel, Beschreibung und Bruttopreis eintragen und auf Aktivieren stellen.

5
Kapitel & Vorlauf-Schutz im Code hinterlegen Frontend Code

• In src/pages/AudiobookPage.tsx das Kapitel-Array (Titel, Startzeit in Sekunden) eintragen.
• Den Vorlauf-Schutz (rechtlicher Hinweis z. B. 69 Sek. für 01:08 Min.) für dieses Buch aktivieren.

6
Kompilieren & auf Hostinger veröffentlichen Hostinger / Deploy

• Im Terminal npm run build ausführen.
• Die erzeugten Dateien aus dist/ auf den Hostinger Server in den Ordner public_html hochladen (per Web-FTP oder automatischer Git-Synchronisation).

Datenbank-Tabellen, Rollen & Fehlerbehebung

Alle Nutzerdaten, Freischaltungen und Admin-Rechte werden in Supabase gespeichert. Nachfolgend die Schlüssel-Tabellen und Standard-Lösungen für den Support:

1. Die 3 zentralen Tabellen in Supabase

Tabelle: produkte

Enthält den Katalog aller Produkte.
Wichtige Spalten:
• id (z. B. mensch_sein)
• titel, beschreibung
• audio_path (Cloudflare Link)
• dauer (Sekunden)
• play_store_id (z. B. fds_mensch_sein)

Tabelle: kaeufe

Verknüpft Nutzer mit ihren freigeschalteten Produkten.
Wichtige Spalten:
• user_id (Supabase Auth UID)
• produkt_id (entspricht produkte.id)
• created_at (Kaufzeitpunkt)
• status (completed)

Tabelle: profiles

Nutzerdaten & Berechtigungsstufen.
Wichtige Spalten:
• id (UID aus Auth)
• email (Normalisierte Mailadresse)
• rolle: 'admin' oder 'user'
• is_premium (Abo-Status)

2. Wichtige Regeln für reibungslosen Betrieb

E-Mail Alias-Gleichbehandlung

Im Code ist eine automatische Normalisierung integriert: @googlemail.com und @gmail.com werden für dieselbe Person identisch behandelt. Käufe und Admin-Rechte bleiben so bei SSO-Logins immer erhalten.

Flugmodus & Offline-Speicher

Gekaufte Hörbücher werden im geschützten App-Speicher (IndexedDB / Capacitor) abgelegt. Die MP3-Datei liegt niemals ungeschützt im Dateisystem. Der Offline-Player merkt sich die genaue Hörposition automatisch im localStorage.

3. Schnelle Hilfe bei typischen Fragen / Problemen

Problem Ursache Sofort-Lösung
Admin-Rechte nach Login weg Login mit neuem SSO-Konto oder geänderter E-Mail-Adresse. In Supabase Tabelle profiles den Nutzer suchen und Spalte rolle manuell auf admin setzen. (Das System besitzt zusätzlich eine Self-Healing-Funktion).
Neues Hörbuch wird nicht angezeigt Eintrag in Supabase Tabelle produkte fehlt oder Cache aktiv. 1. Prüfen ob die Zeile in produkte existiert.
2. Browser-Cache leeren mit Strg + F5.
3. Prüfen ob dist/ auf Hostinger hochgeladen wurde.
Audio spielt nicht ab / bricht ab Cloudflare R2 Link falsch oder CORS blockiert Range Requests. 1. Öffentliche URL im Browser direkt testen.
2. Cloudflare R2 CORS prüfen (GET, HEAD und Header Range müssen erlaubt sein).
In-App-Kauf auf Android schlägt fehl Produkt-ID in Google Play weicht von Supabase play_store_id ab. In der Google Play Console prüfen, ob das In-App-Produkt aktiv ist und die ID exakt (z. B. fds_mensch_sein) übereinstimmt.
Google Login zeigt falsche Domain Zustimmungsbildschirm in Google Cloud Console nicht auf Produktion. In Google Cloud Console > APIs & Dienste > OAuth-Zustimmungsbildschirm die autorisierte Domain flow-der-stille.de prüfen (Status: In Produktion).
